# Prompts — Team/Human Introduction Reel (Day 6)

This Reel is built entirely from **real footage of an actual ArasSystem
team member** — no AI-generated talking-head or synthetic voice is used
or should ever be used for this content, since it would misrepresent who
is speaking. The prompts below are editing/assembly prompts for the real
input clip, not generative-video prompts.

## MASTER VIDEO PROMPT (assembly/editing prompt)
```
Assemble a 9:16, ~25-second vertical Reel from one real input clip (a
team member speaking to camera, provided as input — no generated video):
1. [CLIP: team-intro-raw.mp4] trimmed/cut per script.md into the 5 scenes
   (0–2s hook, 2–8s context, 8–16s what's changing, 16–22s invitation,
   22–25s close).
Composition: full-bleed 9:16 vertical, natural framing, minimal on-screen
text (per design-direction.md) appearing only at the timestamps specified
in storyboard.md.
Text overlay style: same Persian-capable sans-serif system as other Week
1 assets, used sparingly.
Transitions: hard cuts only, or none if kept as one continuous take.
Audio: keep the real recorded voice/room audio as the primary track;
optional very low-volume warm/calm background music.
Aspect ratio: 9:16, 1080×1920 export.
Exclude: any AI-generated face/voice, any scripted-sounding re-dub, any
permanent logo/brand color treated as final.
```

## MASTER COVER PROMPT (compositing prompt)
```
Use the real frame from [CLIP: team-intro-raw.mp4] at the hook moment
(0–2s) as the cover image, 9:16 (1080×1920). No text overlay needed, or a
minimal short caption only if it improves clarity as a static thumbnail.
No logo lock-in.
```

## ALTERNATIVE VIDEO PROMPT
```
Same real input clip, but keep it as one uncut continuous take (no
internal cuts) if the recording naturally flows well — sometimes less
editing reads as more authentic for this format.
```

## REGENERATION / REVISION PROMPT
```
Re-edit using the same real clip: [describe specific change, e.g.
"trim the opening by 1s" / "add on-screen text at 00:10"]. Do not
substitute any different footage or a synthetic voice.
```

## NEGATIVE / AVOID INSTRUCTIONS
- No AI-generated or synthetic person/voice under any circumstance
- No stock footage substituting for the real team member
- No heavy color grading or filters that make the footage look
  artificial/inauthentic
- No permanent brand color/logo/font treated as final

## Portability Note
Unlike the portfolio Reel, this format has no meaningful "alternative
image tool" test — there is no image to generate, only real footage to
edit. Any AI video tool used here must operate strictly on the real input
clip (trim/caption/export), never generate new footage of a person.
