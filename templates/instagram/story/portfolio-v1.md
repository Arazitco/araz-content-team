# Template: Portfolio Story Frame (V1)

## When To Use
A single Story frame highlighting one real project detail (a launch
announcement, a single screenshot highlight, a behind-the-scenes moment)
— for a full multi-slide breakdown use
`templates/instagram/carousel/portfolio-design-breakdown-v1.md` instead.

## 1. Content Structure
One observational headline about a real, visible project detail +
optional CTA line ("نمونه‌کارهای بیشتر رو تو آراز سیستم ببینید" or
equivalent, per `knowledge/offers.md`).

## 2. Visual Structure
- Full-bleed 9:16 real screenshot (cropped to the relevant detail) or a
  real project photo — never an AI-recreated interface.
- A soft scrim only where legibility genuinely requires it, positioned so
  it never covers the specific detail the frame is about.
- Consistent margins per `templates/production/overlay-spacing-rules.md`.

## 3. Production Rules
- Output: 1080×1920 (9:16).
- Typography: per `templates/production/typography-system.md`.
- Screenshot treatment: per
  `templates/production/screenshot-treatment.md` — real image only.
- Route: **Route A (Deterministic Local Render)** — real screenshot
  preservation makes this the default; Canva is only appropriate if the
  asset is already Canva-accessible without publishing it.
- Export: PNG, named per `delivery/file-naming-convention.md`.
