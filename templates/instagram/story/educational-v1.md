# Template: Educational Story Frame (V1)

## When To Use
A single-frame or short-sequence Story teaching one quick, useful point
— see `.claude/agents/story-producer.md` for full daily-sequence
planning; this template covers one frame's visual/production shape.

## 1. Content Structure
One headline (the point) + optional one supporting line. Never more than
two short lines on one frame — a Story is glanced at, not read closely.

## 2. Visual Structure
- Full-bleed 9:16 background — neutral/brand-flexible, or a real
  relevant image if one exists and needs no UI reconstruction.
- Centered or upper-third text placement, generous margins.
- A soft scrim only if the background genuinely reduces legibility.

## 3. Production Rules
- Output: 1080×1920 (9:16).
- Typography: per `templates/production/typography-system.md`.
- Route: **Route B (ChatGPT Image)** or **Route C (Canva)** for a
  generic frame; **Route A (Deterministic Local Render)** if the frame
  uses a real website screenshot that must be preserved exactly.
- Export: PNG, named per `delivery/file-naming-convention.md`.
