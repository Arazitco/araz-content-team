# Template: Human/Team Reel (V1)

## When To Use
A Reel featuring a real ArasSystem team member speaking directly to
camera (e.g. a re-introduction Reel) — never a synthetic or AI-generated
person.

## 1. Content Structure

```
0–2s   Hook (team member speaking)
2–?s   Core message, in the team member's own words per the approved
       script
Final  CTA
```

## 2. Visual Structure
- Real, camera-recorded footage of an actual team member only.
- Minimal on-screen text — this format leans on the person speaking, not
  graphic overlays.
- No stock footage standing in for the team member.

## 3. Production Rules
- Output: 1080×1920 (9:16), cover at the same aspect ratio.
- Typography (for any on-screen captions): per
  `templates/production/typography-system.md`.
- Route: this format requires real recorded footage — no production
  route in `.claude/agents/production-connector.md` can substitute for
  it. If footage doesn't exist yet, this is `OWNER ASSET REQUIRED`, not a
  generation task.
- Export: MP4 (Reel) + PNG (cover), named per
  `delivery/file-naming-convention.md`.

## Absolute Rule
Never generate, imply, or use an AI-generated person in place of a real
team member for this format, under any circumstance.
