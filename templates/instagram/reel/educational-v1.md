# Template: Educational Reel (V1)

## When To Use
A Reel teaching one useful idea via on-screen text and conceptual visuals
— no real website UI involved (for that, use `website-showcase-v1.md`).

## 1. Content Structure

```
0–2s   Hook
2–?s   Point 1
?–?s   Point 2 (if the idea needs it — don't force a second point)
Final  CTA
```

## 2. Visual Structure
- Conceptual scenes/visuals matching the point being made — no fabricated
  UI, no invented product screenshots.
- On-screen text: short, one idea per beat, consistent typography
  treatment throughout.

## 3. Production Rules
- Output: 1080×1920 (9:16), cover at the same aspect ratio.
- Typography: per `templates/production/typography-system.md`.
- Route: **Route D (Video AI)** for conceptual/cinematic visuals, or
  **Route A (Deterministic Local Render)** if the Reel is actually a
  sequence of static text/graphic frames rendered locally.
- Never use generative video to recreate an exact website interface —
  that's Route E's job with real screenshots, not this template's.
- Export: MP4 (Reel) + PNG (cover), named per
  `delivery/file-naming-convention.md`.
