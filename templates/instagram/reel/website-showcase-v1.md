# Template: Website Showcase Reel (V1)

## When To Use
A Reel that walks through a real, completed website project via real
screenshots (a "website walkthrough" Reel like the Carlin Ladies Day 1
production).

## 1. Content Structure

```
0–2s   Hook
2–?s   Homepage
?–?s   Key feature / product page
?–?s   Other pages (category, filters, etc.)
?–?s   Mobile view (if a real mobile capture exists)
Final  CTA
```

Scene count and timing follow what real captured material actually
supports — never pad with an invented scene to hit a target duration.

## 2. Visual Structure
- Real screenshots only, animated via pan/zoom/crop transitions — never
  AI-recreated or re-imagined UI.
- On-screen text is observational (what's visibly true), never a claimed
  business result or invented visitor intent.
- Consistent scrim/overlay rules per
  `templates/production/overlay-spacing-rules.md`.
- Cover frame: one clear, representative screenshot moment with the
  Reel's hook text.

## 3. Production Rules
- Output: 1080×1920 (9:16), cover at the same aspect ratio.
- Typography: per `templates/production/typography-system.md`.
- Screenshot treatment: per
  `templates/production/screenshot-treatment.md`.
- Route: **Route E (Deterministic Website Motion)** — real screenshots
  animated via deterministic pan/zoom rendering, never generative video
  reconstruction of the site's UI.
- Export: MP4 (Reel) + PNG (cover), named per
  `delivery/file-naming-convention.md`.
