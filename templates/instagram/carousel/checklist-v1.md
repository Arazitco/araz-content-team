# Template: Checklist Carousel (V1)

## When To Use
A scannable, save-worthy list format (e.g. "5 things every website
homepage needs") — distinct from `educational-v1.md`'s narrative build-up.

## 1. Content Structure

```
Slide 1 — Hook naming the list ("N things ...")
Slide 2..N-1 — One checklist item per slide, numbered
Slide N — Recap of the list + CTA
```

Every item must be genuinely independent and useful on its own (a reader
skipping to any one slide should still get value).

## 2. Visual Structure

- Consistent numbered badge/marker style across all item slides.
- One item per slide: short label + one line of explanation, no more.
- Consistent margins and alignment across the set (see
  `templates/production/overlay-spacing-rules.md`).
- Final recap slide may list all items compactly, plus the CTA.

## 3. Production Rules

- Output: 1080×1350 (4:5), consistent across every slide.
- Typography: per `templates/production/typography-system.md`.
- Route: **Route B (ChatGPT Image)** or **Route C (Canva)** — no
  real-screenshot dependency.
- Export: PNG, named per `delivery/file-naming-convention.md`.
