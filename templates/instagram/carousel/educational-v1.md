# Template: Educational Carousel (V1)

## When To Use
A text-driven carousel teaching one specific, useful idea (web design,
UX, SEO) — not a portfolio breakdown (use
`portfolio-design-breakdown-v1.md` for that) and not a checklist (use
`checklist-v1.md` for that).

## 1. Content Structure

```
Slide 1 — Hook (the question or claim that stops the scroll)
Slide 2..N-1 — One idea per slide, each building on the last
Slide N — Takeaway + CTA
```

Keep each interior slide to one idea only — never combine two unrelated
points on one slide. Slide count follows what the topic actually
supports (typically 5–8); never pad to hit a round number.

## 2. Visual Structure

- Background: neutral, calm, brand-flexible (per
  `brand/visual-identity.md`, status PENDING REDESIGN) — no invented
  permanent colors.
- One headline per slide, generous whitespace, consistent margins across
  the set (see `templates/production/overlay-spacing-rules.md`).
- Supporting line only where it adds something the headline doesn't
  already say.
- No stock photography, no generic AI-style graphics, no decorative
  clutter.

## 3. Production Rules

- Output: 1080×1350 (4:5), consistent across every slide.
- Typography: per `templates/production/typography-system.md`.
- Route: **Route B (ChatGPT Image)** or **Route C (Canva)** — this
  format has no real-screenshot preservation requirement, so Canva's
  ingestion limits don't apply the way they do for portfolio content.
  Prefer whichever route the Production Router selects based on
  editability needs.
- Export: PNG, named per `delivery/file-naming-convention.md`.
