# ArasSystem Content Pillars (V1)

Defines the V1 content pillar system used by `content-planner`,
`content-writer`, `story-producer`, and `portfolio-producer`. Strategic
context lives in `strategy/content-strategy.md`; business facts live in
`knowledge/*.md`.

The 70% Website Design / 30% SEO default mix (see
`strategy/content-strategy.md`) governs the balance across these pillars.

**Pillar Quality Rule** — every proposed topic should answer at least one:
- What does the audience learn?
- What decision becomes easier?
- What mistake is avoided?
- What proof is shown?
- What trust is created?
- What business problem is clarified?

If none apply, the topic probably does not belong in the content strategy.

---

## A. Website Design — Default 70%

### 1. Portfolio & Case Studies
Completed websites, project showcases, before/after, why we designed it
this way, feature walkthrough, industry-specific portfolio, customer
problem → design solution.

### 2. Website Strategy
What a business website should actually do, website planning, choosing the
right site type, business goals before design.

### 3. UX / UI
Navigation, mobile UX, visual hierarchy, usability, clarity, user
friction.

### 4. Website Mistakes
Confusing homepage, weak CTA, poor mobile experience, credibility
problems, unnecessary complexity.

### 5. Conversion & Business Impact
Website → trust, website → lead, customer journey, conversion logic,
credibility. Avoid guaranteed financial claims.

### 6. Website Redesign
When redesign is needed, before/after, redesign decisions, outdated UX
patterns.

### 7. Work in Progress / Behind the Scenes
Design process, project progress, UI preview, technical decisions
explained simply, review/iteration.

### 8. Website Education
Corporate vs e-commerce, hosting, support, domains, WordPress, website
planning. Stay within confirmed ArasSystem services (see
`knowledge/services.md`).

### 9. Website Trends / Expert Commentary
Use selectively. Do not chase trends solely for reach.

## Historical Account Learning

The historical Instagram baseline (see `strategy/content-strategy.md`)
should influence V1 without being blindly repeated. Do not simply
recreate: large volumes of generic SEO cards, repetitive static
education, Threads repost clusters, or disconnected seasonal promotions.

Instead, test stronger combinations of: expert/human delivery, real
project proof, visual website demonstrations, conversational formats,
useful education, business-oriented website insights, and strategic
Stories. These are test directions, not guaranteed winners.
