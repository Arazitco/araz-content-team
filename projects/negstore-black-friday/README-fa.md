# لندینگ بلک فرایدی نگ استور — «سه شبِ مخمل»

## کانسپت
نگ استور جواهر لوکس می‌فروشد؛ لحظه‌ی کلیدی خرید جواهر، **باز شدن جعبه** است. کل صفحه حول همین ایده ساخته شده:

- **هیرو:** جعبه‌ی مخملی شرابی برند که درِ آن باز می‌شود و انگشتر از بالشتک بالا می‌آید (CSS/SVG، بدون عکس سنگین).
- **شمارش معکوس:** به‌شکل برچسب‌های قیمتِ آویزان روی نخ، نه کادرهای عددی تکراری.
- **دسته‌بندی‌ها:** «کشوهای جعبه»؛ با کلیک، ویترین همان‌جا فیلتر می‌شود و کاربر از لندینگ خارج نمی‌شود.
- **کارت محصول:** قاب طاق‌دار ویترین جواهرفروشی + برچسب تخفیف آویزان.
- **CTA پایانی:** «جعبه، شب ۸ آبان بسته می‌شود».
- نوار متحرک شرابی از نوار دسته‌بندی صفحه اصلی سایت گرفته شده تا لندینگ جدا از سایت به نظر نرسد.

پالت فقط از رنگ‌های برند است (شرابی `rgb(75,17,29)`، کرم `rgb(255,241,232)`، سفید) به‌اضافه‌ی مشکیِ مایل به شرابی برای حس بلک فرایدی. رنگ تازه‌ای اضافه نشده.

## چرا هر سکشن هست
| سکشن | دلیل |
|---|---|
| هیرو + تایمر + شب‌های کمپین | معرفی پیشنهاد، تاریخ دقیق و فوریت، همه بالای صفحه |
| نوار متحرک | تکرار پیشنهاد اصلی (ارسال رایگان / حداکثر تخفیف) و پیوند بصری با سایت |
| ویترین حراج (فیلتر + مرتب‌سازی + کارت) | کوتاه‌ترین مسیر به خرید؛ فقط محصولات تخفیف‌دار واقعی |
| پرفروش‌ها | اثبات اجتماعی بر اساس فروش واقعی، بدون نظرسنجی یا رضایت ساختگی |
| اعتماد | چهار مزیتی که خود سایت اعلام کرده؛ هیچ ادعای تازه‌ای اضافه نشده |
| CTA پایانی + نوار چسبان موبایل | برگرداندن کاربر مردد به ویترین |

## اتصال زنده به ووکامرس
وقتی صفحه روی negstore.com باشد، اسکریپت بدون PHP و بدون افزونه از **WooCommerce Store API** (عمومی و فقط‌خواندنی) داده می‌گیرد:

- `GET /wp-json/wc/store/v1/products?on_sale=true&per_page=100` ← ویترین، فیلتر دسته، **حداکثر درصد تخفیف هیرو** (به‌صورت خودکار از قیمت‌های واقعی محاسبه می‌شود)
- `GET /wp-json/wc/store/v1/products/categories` ← تصویر و نام دسته‌ها (فقط دسته‌هایی که محصول تخفیف‌دار دارند نمایش داده می‌شوند)
- `GET /wp-json/wc/store/v1/products?on_sale=true&orderby=popularity` ← پرفروش‌ها
- افزودن به سبد: `?wc-ajax=add_to_cart` (همان endpoint دکمه‌های آرشیو وودمارت) و سپس رویداد `added_to_cart`، تا مینی‌کارت/پاپ‌آپ وودمارت به‌روز شود. محصولات متغیر به صفحه‌ی محصول می‌روند.

**تست پیش از نصب:** آدرس `https://negstore.com/wp-json/wc/store/v1/products?on_sale=true` را در مرورگر باز کنید. اگر JSON محصولات برگشت، اتصال کار می‌کند. اگر 401/403/404 گرفتید، احتمالاً افزونه‌ی امنیتی REST API را بسته یا نسخه‌ی ووکامرس قدیمی است؛ باید مسیر `wc/store/v1` برای مهمان‌ها باز شود.

اگر API در دسترس نباشد (مثل پیش‌نمایش همین فایل)، صفحه به **حالت نمونه** می‌رود: نوار زرد بالای صفحه و برچسب «داده نمونه» روی هر کارت نشان می‌دهد که داده‌ها واقعی نیستند، و دکمه‌ی خرید غیرفعال است.

### پیش‌نیاز قیمت‌ها
تخفیف‌ها باید در خود ووکامرس با **قیمت حراج زمان‌بندی‌شده** (از ۶ تا ۸ آبان) ثبت شوند. لندینگ فقط آن‌ها را نمایش می‌دهد. قبل از ۶ آبان، اگر حراجی ثبت نشده باشد، ویترین پیام خالی و لینک فروشگاه را نشان می‌دهد.

## نصب در المنتور
1. یک برگه‌ی جدید با قالب «Elementor Canvas» یا «Elementor Full Width» بسازید.
2. یک ویجت **HTML** با عرض کامل اضافه کنید.
3. از `index.html` فقط بین دو کامنت `شروع کد قابل انتقال` و `پایان کد قابل انتقال` را کپی کنید (شامل `<style>`، محتوا و `<script>`). تگ `<link>` فونت گوگل را **کپی نکنید**؛ فونت‌های دوران و وزیر از قالب ارث‌بری می‌شوند.
4. اگر نام فونت عنوان در قالب چیزی غیر از `Doran` ثبت شده، متغیر `--nbf-font-head` را اصلاح کنید.
5. عنوان سئو و توضیحات متا را در Rank Math/Yoast بگذارید (متن پیشنهادی در `<title>` و `<meta name="description">` همین فایل هست).

همه‌ی کلاس‌ها با پیشوند `nbf-` زیر `#nbf` محدود شده‌اند و با استایل‌های وودمارت تداخل ندارند.

### تنظیمات بدون دست زدن به کد
پیش از اسکریپت اصلی می‌توانید این را اضافه کنید:
```html
<script>
window.NEG_BF_CONFIG = {
  start: "2026-10-28T00:00:00+03:30",
  end:   "2026-10-30T23:59:59+03:30",
  shipText: "ارسال رایگان به سراسر ایران",
  shopUrl: "/shop/",
  maxDiscountOverride: null
};
</script>
```

## مواردی که مالک باید تأیید کند
1. **سقف تخفیف:** عدد «تا X٪» عمداً از قیمت‌های واقعی محاسبه می‌شود. در پیش‌نمایش ۳۱٪ نمایش داده می‌شود که از داده‌ی نمونه است، نه عدد واقعی کمپین. «۵۰٪» در بریف فقط مثال بود و استفاده نشد.
2. **شرایط ارسال رایگان:** متن فعلی «ارسال رایگان به سراسر ایران، بدون حداقل خرید» را فرض گرفته. اگر حداقل مبلغ دارد، `shipText` را تغییر دهید.
3. **نام برندهای اصلی (ون‌کلیف، بولگاری، هرمس):** عمداً در لندینگ استفاده نشده. فروش «های‌کپی» با نام برند ثبت‌شده ریسک حقوقی دارد و تبلیغ آن در گوگل و متا به‌احتمال زیاد رد می‌شود. پیشنهاد: «طرح جواهر» یا نام کالکشن خودتان.
4. **تاریخ:** ۶ تا ۸ آبان ۱۴۰۵ معادل ۲۸ تا ۳۰ اکتبر ۲۰۲۶ است؛ بلک فرایدی جهانی ۶ آذر (۲۷ نوامبر) است. برای بازار ایران مشکلی نیست، فقط آگاهانه باشد.
5. **مرجوعی/گارانتی:** چون سیاستش را نداشتم، ادعایی درباره‌اش اضافه نکردم.
